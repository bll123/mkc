### Syntax: .check_include_compile

__.check\_include\_compile__ checks to make sure the specified include
files will compile without any dependencies.

__.check\_include\_compile__ uses the compiler flags set by the user
for the include compilation tests.

    .check_include_compile {
      # note that the match expression is a full regular expression
      # and not a basic regular expression.
      .match <pattern>;
    }

##### Examples

    .check_include_compile {
      .match '\.h$';
    }

##### Attributes

* [.match](SyntaxAttrMatch)
