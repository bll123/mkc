**0.8 2026-10-21**

* Bug Fixes:
    * Various
* Changes:
    * All keywords now have a leading period (.).
* New Features:
    * create_file
    * command (attribute)

**0.7 2026-10-1**

* Bug Fixes:
    * Various fixes for 'check_include...'.
    * File timestamps at millisecond resolution.
    * Many other fixes.
* Changes:
    * Cache invalidation is more particular.
* New Features:
    * Define executable.
    * Build.

**0.6 2026-7-31**

* Changes:
    * The 'check_include_...' statements are now efficient.
    * Remove 'set temporary'.
* New Features:
    * set local
* Internal:
    * Re-write variable handling.

**0.5 2026-7-15**

* Bug Fixes:
    * Fix check/success/fail processing.
    * Fix local variable processing.
    * Fix check_include_guards on windows.
* New Features:
    * set temporary  ...
    * return (function).

**0.4 2026-7-14**

* Bug Fixes:
    * Fix 'continue' statement.
    * Fix unary-op type check.
* New Features:
    * Add 'check_include_guards'.
    * Add 'check_include_compile'.
    * Add 'success', 'failure' attribute.
    * Units: 'units/commonpaths.mkc', 'units/libintl.mkc'.

**0.3 2026-7-10**

* Bug Fixes:
    * Various
* Changes:
    * 'path' attribute is repeatable.
* New Features:
    * Add 'check_include_dependencies'
    * Add 'foreach'
    * Add 'function'

**0.2 2026-7-5**

* Bug Fixes:
    * Fix relative path location for share directory.
    * Fix repeatable attributes.
* New Features:
    * Add 'check_header'.
    * Add 'replace' attribute for 'configure'.
    * Add 'alternate' attribute.

**0.1 2026-7-3 pre-alpha**

* First pre-alpha release.
    * Can only create configuration files.
